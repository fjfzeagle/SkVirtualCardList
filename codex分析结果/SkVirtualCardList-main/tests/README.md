# 回归验证

`RegressionTests.dpr` 是不依赖测试框架的 Delphi 断言入口，使用真实的列表、文本测量、轮播渲染器和异步执行器。

当前 macOS 环境没有 Delphi 编译器；此入口尚未编译或运行，不能将源码/模型检查当作测试通过。

## 原生测试

1. 在安装 Delphi、FMX 和 Skia 的 Windows 环境打开 `RegressionTests.dpr`。
2. 使用与主工程一致的 Delphi 版本及 Win32/Win64 库路径，按 Skia 的部署要求提供原生库。
3. 编译并运行控制台程序。成功输出 `All regression tests passed.`，失败返回非零退出码。

覆盖：分页失败后保持可重试、Clear 重置加载状态、布尔 FinishFetch 只测量新增项、MaxLines(2) 测量、Wrap 无限行兼容、轮播多帧不重建卡片布局、改数据仍失效缓存、延迟模式加载不覆盖后续选择、过期分页不追加/关闭窗体后回调安全、回调抛异常后 Finally 执行。

## 主程序手工回归

- 启动后 600ms 内连续点击单列、双列、订单：最终只显示最后选择的模式。骨架期间点空状态，应持续为空。
- 在请求下一页时切换模式或关闭窗体：旧结果不应追加、弹窗或访问已销毁的控件。
- 加载更多期间下拉、刷新期间继续滚动：只允许一个请求；完成后可再次拉取，页码正确。
- 打开故障模拟并触发分页，失败后关闭故障、继续滚动：应重试原页，不显示数据耗尽。商品/商家每页 20 条、订单每页 5 条，分页编号不重复。
- 点击坏图测试，分别滑到第 2/3 张并点击：只重试当前图；用不含 404 的不可达地址验证同一逻辑。商家和订单明细图也应可以重试。
- 首张向右、末张向左，含超出一个图片宽度的拖动：轮播应连续覆盖图片区域。
- 长标题 MaxLines(2) 最多两行，末行省略；普通单行截断；商品长地址 Wrap(True) 仍完整折行。
- 改价、换图、旋转窗口后，布局和热区应更新。单列变高检查后续平移；双列变高检查全量重排结果。

## 性能测量

在目标手机分别加载 1 千/1 万条数据，记录快速滚动、自动轮播、局部改价和分页追加时的帧耗时及峰值内存；弱网下记录重复订阅数量、完成回调耗时；空闲和骨架阶段记录唤醒/耗电。当前没有设备基准，未宣称具体帧率提升。
